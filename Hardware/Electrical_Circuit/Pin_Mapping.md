# Pin Mapping

| ---------- | --- | ------------- |

|            | A0  | GPIO 34       |

|            | SCL | GPIO 22 (I2C) |
| LCD        | SDA | GPIO 21 (I2C) |
|            | SCL | GPIO 22 (I2C) |
| Buzzer     | +   | GPIO 23       |
